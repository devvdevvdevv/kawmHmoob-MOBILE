✅ **CONSUMED 2026-09-14.** All 64 came back as a compact list and all 64 were
applied — see `notes/2026-09-14-zong-vang-day-two.md`, thirty-first pass.

Kept as a stub rather than removed, because the return format it specified is
the one that worked after JSON hit the 50,000-character message ceiling twice:

```
[REPLACE |compound_only ]word: sense one | sense two | NOTE: … | REVIEW: …
```

- `REPLACE` — what is on file is **wrong**. Everything there goes away.
- `compound_only` — the bare word is not usable alone; name the compound.
- `REVIEW:` — unconfirmed. Tagged `needs-source-review`, stays in the queue.
- Omitted = incomplete, **not wrong**. Senses already on file are kept.
