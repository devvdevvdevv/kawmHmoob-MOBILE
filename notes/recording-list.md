## How to add a clip

1. Record the word on its own, normally spoken. One word per file, mp3.
2. Save it at the path in the table, e.g. `assets/audio/vocabulary/colors/liab.mp3`.
3. Set the entry's `audioFile` in `src/data/vocabulary.js` to the same path
   without the `assets/audio/` prefix — e.g. `audioFile: 'vocabulary/colors/liab.mp3'`.
4. `node scripts/generate-audio-map.js` — Metro needs a literal `require()` per
   file, so a clip that is not in `src/lib/audioMap.js` will not play.
5. `node scripts/recording-list.mjs --write` to refresh this list.
