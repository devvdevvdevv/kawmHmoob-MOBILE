# Session 1a — the alphabet

Every letter and every tone the Reference tab teaches, and the first Hmong
anyone hears in this app. **All of these already have a clip**, so the whole
file is `overwrite`: the new take replaces the old one at the same path.

Say the letter as the alphabet lessons teach it, then its example word where
there is one. The tone rows matter most — record those eight in one take,
in this order, so the pitches are relative to each other.
