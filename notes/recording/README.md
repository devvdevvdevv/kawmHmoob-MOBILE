## Why these modules and not the whole dictionary

The vocabulary is 1259 spellings. Session 1 is the 220 items that the
**taught** screens read from — the alphabet, the path's units, the Reference
grammar tables, the sentence builder. Everything left over is mostly the
reader's lookup glossary, which nobody is taught and which can wait until a
voice is proven rather than being chosen.

## ⚠️ Read this before the session

- **The new file goes at the same path as the old one.** No code or data
  changes; a new file at a known path just plays.
- **The originals are in `archive/2026-09-22-audio-v1/`** (315 clips) — the only
  copy. Do not delete it until the new set has been heard on a device.
- **`overwrite` vs `new` in the last column.** A missed `new` row is a silent
  button; a missed `overwrite` row leaves the OLD VOICE in the app beside the
  new one. The mixed-voice case is the one to check for at the end.
- **One item per file, mono.** Record a WAV master (48 kHz) and keep it outside
  the repo; export mp3 to the paths in the tables. The repo carries 41 MB of
  audio today.
- **A clip is the word alone** — no "the word for dog is…", no English. The
  screen supplies the context.
- **Let the final consonant be heard.** In RPA the tone IS that last letter,
  and the typing drill teaches exactly that.

## The speaker

- Get permission in writing for the recordings to ship in a paid app, and ask
  how they want to be credited (`app/about.jsx` holds the credits).
- Write down who recorded it and when, so the next person can match the voice
  instead of guessing.

## After the session

1. Drop the files in at the paths in the tables.
2. `node scripts/generate-audio-map.js` — strictly only needed for **`new`**
   rows, but always safe, and an unmapped clip is silent with no error at all.
3. `node scripts/recording-list.mjs --write` — the gap list should shrink.
4. Listen **in the app**, not in a file browser: one tone, one path word, one
   long word. Then walk a flashcard deck and a unit's Tones step.

## Finding a clip that still has the old voice

```sh
find assets/audio -name "*.mp3" -newermt 2026-09-22 | wc -l   # re-recorded
find assets/audio -name "*.mp3" ! -newermt 2026-09-22         # still the old voice
```
